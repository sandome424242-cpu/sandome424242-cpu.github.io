三度目の命日 公式サイト v8
もっと色どぎつい・変なフォント・古の個人サイト版

==================================
Macで完全版を開く方法
==================================
1. ZIPを解凍
2. フォルダ内の「start_preview.command」をダブルクリック
3. Safariでサイトが開きます
4. 終了するときはターミナルで Control + C

もし開けない場合:
ターミナルでこのフォルダに移動して

python3 -m http.server 8000

を実行し、
Safariで http://localhost:8000 を開いてください。
